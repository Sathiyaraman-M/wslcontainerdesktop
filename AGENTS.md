# AGENTS.md

- This is a fork of [mhackermsft/wslcontainerdesktop](https://github.com/mhackermsft/wslcontainerdesktop), primarily intended to adopt [BlazorWinUI](https://github.com/Sathiyaraman-M/BlazorWinUI) for writing UI with Blazor, instead of XAML.
- Although this is the long-term goal, the idea is to incrementally adopt UI sections to use Blazor while pointing our missing controls and gaps in BlazorWinUI, which would be continuously addressed along the Journey.
- At the end of this adoption exercise, the current project should be much simpler than the original project to manage, while maturing the dependent BlazorWinUI library to fairly usable state.
